# Услуги — кликабельный прототип

Статичная выгрузка макета сервиса заказа услуг (мобильная, планшетная и десктопная версии).

- `index.html` сам выбирает версию по ширине экрана.
- Принудительно: `index.html?device=mobile`, `?device=tablet`, `?device=desktop`.
- Экраны: главная, категория «Баня», карточка услуги, корзина, подтверждение бронирования.

Публикация: Settings → Pages → Deploy from a branch → `main` / root.
