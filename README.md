# Услуги — кликабельный прототип

Статичная выгрузка макета сервиса заказа услуг отеля (телефон, планшет, десктоп).

- `index.html` сам выбирает версию по ширине экрана; принудительно: `?device=mobile|tablet|desktop`.
- Бейдж «Все» и 11 разделов-фильтров (повторное нажатие на раздел возвращает на «Все»), подразделы в Питании, СПА, Бане и Трансфере; 41 услуга.
- Почасовые услуги (баня, СПА, прокат, трансферы, экскурсии, детские) по «+» открывают окно выбора параметров; поштучные (питание, подарки, парковка) добавляются в корзину сразу.
- Рабочая корзина хранится в браузере тестировщика. `?reset` в адресе очищает её, `?demo` кладёт две услуги для примера.
- На десктопе справа внизу демо-панель: фото отеля в шапке, объём стилей («Только акцентный цвет» / «Все стили») и стили отеля («Дефолтный» / «Cosmos» / «Охта Парк» / «Территория»: вместе с отелем меняются логотип, фото и заголовок). Выбор запоминается между страницами.
- A/B-тест разделов завершён, победил вариант с «Все»: `index.html?ab=a` (старый вид с крестиком) и `index.html?ab=b` (с «Все»). В обоих вариантах дефолтная тема без фото в шапке и без демо-панели; вариант запоминается в браузере. `index.html` без `ab` возвращает обычный прототип.
- Экраны ошибок: на десктопе селект «Ошибка» в демо-панели; на любой главной (`Main.html`, `MainTablet.html`, `MainDesktop.html`) — `?err=unavailable|link|tech|tech-loaded|soldout|past|auth`.
- Шапка с фото сжимается при прокрутке и после первого добавления в корзину.
- Фото услуг — Unsplash (бесплатная лицензия).
