# Услуги — кликабельный прототип

Статичная выгрузка макета сервиса заказа услуг отеля (телефон, планшет, десктоп).

- `index.html` сам выбирает версию по ширине экрана; принудительно: `?device=mobile|tablet|desktop`.
- 11 категорий, 41 услуга, рабочая корзина — она хранится в браузере тестировщика.
- Добавьте `?reset` к адресу любой страницы, чтобы очистить корзину, или `?demo`, чтобы положить в неё две услуги для примера.
- Фото новых услуг — Unsplash (бесплатная лицензия), подгружаются с images.unsplash.com.
